# Кастомизация POLY Fantasy Female

В сцене `Demonstration` выберите корневой объект `POLY_FantasyFemale_Unity`. Компонент **Female Character Customizer** показывает настройки торса, брюк, обуви, волос, бровей, палитры и каждой руки. Изменения видны в редакторе; поддерживаются Undo/Redo.

Для новых персонажей используйте `Prefabs/POLY_FantasyFemale_Customizable.prefab`. Каждый экземпляр имеет независимый выбор внешности.

## Правила

| Выбор | Какие части используются |
|---|---|
| Босиком | Длинные брюки `_01` и стопы `CHR_Legs` |
| Низкая обувь E/F | Длинные брюки `_01`; стопы скрыты |
| Высокая обувь A–D | Короткие брюки `_02`; стопы скрыты |
| Рука Full, без перчатки | Цельная `_01`, уже содержащая кисть и пальцы |
| Рука Split, без перчатки | Верх `_02` и предплечье `_03`, уже содержащее кисть и пальцы |
| Перчатка A/C/D | Верх `_02` и перчатка; прежнее предплечье, кисть и пальцы скрыты |
| Перчатка B | Верх `_02`, перчатка и отдельные открытые пальцы; ладонь и запястье скрыты |

Перчатки этого набора занимают всё предплечье. Режим Full/Split и выбранный вариант предплечья сохраняются под перчаткой и возвращаются при её снятии. Верхняя часть руки соответствует торсу; для составной руки можно независимо выбрать один из четырёх вариантов предплечья.

В Inspector доступны случайная внешность и Copy/Paste appearance. Буфер содержит только параметры персонажа в JSON. Перенос между экземплярами не меняет их скелеты.

## Проверенные модели

Исследованы все 60 частей исходного женского FBX: 4 торса, 8 вариантов брюк, 24 части рук, 8 перчаток, 6 пар обуви, 2 кисти, 1 пара стоп, 1 голова, 3 причёски и 3 пары бровей. Длинной туники, плаща и шлемов с исходного изображения в этом FBX нет.

В `GeneratedMeshes` создаются четыре производных меша: открытые пальцы L/R для B и очищенные предплечья D L/R. В исходных предплечьях D одна и та же поверхность присутствует дважды. Генератор удаляет совпадающие треугольники, сохраняя веса, UV, нормали, bindposes и blend shapes. Исходный FBX и исходный префаб не перезаписываются.

Подробный перечень частей, размеры и визуальные проверки находятся в `Documentation/GEOMETRY_AUDIT_RU.md`.

## API для игры

```csharp
using Animpic.FantasyCharacter;

var character = GetComponent<FemaleCharacterCustomizer>();
var appearance = character.CaptureSelection();
appearance.footwear = 1; // 0 = босиком; 1..6 = A..F
appearance.leftGlove = 2; // 0 = нет; 1..4 = A..D
if (!character.TryApply(appearance, out var error))
    UnityEngine.Debug.LogWarning(error);

string saved = character.SaveJson();
character.TryLoadJson(saved, out error);
```

`CaptureSelection()` возвращает копию. Чтобы применить отредактированную копию, вызовите `TryApply`. Сохранение JSON не записывает файлы автоматически: строку можно передать существующей системе сохранений. Формат содержит `schemaVersion: 1`.

Настроенный префаб применяет сохранённую внешность в `Awake`. `Configure(catalog)` только назначает каталог; затем нужен `TryApply`. Для создания нового экземпляра предпочтительно использовать готовый префаб.

Параметры: torso/pants 0..3; footwear 0..6; leftGlove/rightGlove 0..4; hair/brows 0..3 (0 — отсутствуют); palette 0..5; leftForearmStyle/rightForearmStyle -1 — как торс, 0..3 — A..D. `Randomize(seed, out error)` воспроизводим и не меняет общий генератор случайных чисел Unity.

Перед изменениями проверяются каталог, ссылки на меши, имена и порядок костей, параметры и обязательные части. Некорректный выбор отклоняется целиком. Runtime переключает видимость рендереров и использует существующий скелет. Он не меняет исходные материалы и не требует включать Read/Write на FBX.

## Настройка и проверки

Меню **Tools → Animpic Studio → Characters → Fantasy Character**:

- **Set up customization** — построить каталог, производные меши и настраиваемый префаб; настроить женский персонаж, если открыта Demonstration. Перед изменением сцены сохраняется копия её текущего состояния, включая несохранённые изменения.
- **Validate customization** — проверить сочетания одежды и частей тела в изолированном экземпляре.
- **Render examples** — получить изображения сочетаний из Unity.
- **Validate in Play mode** — короткая проверка работы в Play Mode с автоматическим возвратом в Edit Mode.

Отчёты и резервная копия сцены сохраняются в `Library/AnimpicFemaleValidation` проекта. Содержимое Library служебное: важные отчёты можно сохранить отдельно.

При замене исходного FBX перестройте каталог и повторите проверки. Генератор маски пальцев требует точного совпадения с исследованной геометрией; изменение топологии требует нового аудита. Система предназначена для POLY_FantasyFemale_Unity, а не для мужского или произвольного стороннего скелета.

## Использованные подходы

У [UMA Wardrobe Recipe Editor](https://github.com/umasteeringgroup/UMA/blob/master/UMAProject/Assets/UMA/Docs/WardrobeRecipeEditor.md) разделены выбор предмета, скрытие частей тела и подавление несовместимой одежды. У [Synty Sidekick](https://syntystore.com/en-gb/products/sidekick-modular-characters-starter-pack) отдельно представлены торс, верхняя/нижняя части рук, кисти, ноги и стопы. Эти принципы использованы для собственной системы на реальных деталях Animpic; сторонние пакеты для её работы не нужны.

Правила конкретных сочетаний выведены из геометрии POLY Fantasy Female. [Unity Mesh.bindposes](https://docs.unity3d.com/2021.3/Documentation/ScriptReference/Mesh-bindposes.html) объясняет соответствие индексов костей и bind poses. Ограничения [Mesh.isReadable](https://docs.unity3d.com/2021.3/Documentation/ScriptReference/Mesh-isReadable.html) учтены: runtime проверяет заранее сохранённые сведения о скелете без чтения массивов непрочитываемых мешей.
