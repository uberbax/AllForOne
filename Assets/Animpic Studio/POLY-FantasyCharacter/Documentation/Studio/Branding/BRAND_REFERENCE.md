## Practical Unity translation (design recommendation, not a copied website layout)

Use a dark cool studio canvas, a contained rounded header with the original PNG wordmark, one strong blue-to-cyan action, and dark outlined settings controls. Use Manrope for “Character Studio” and section headings; Inter for options and help. Retain44px arrows and sliders, generous24px panel padding,8–12px control gaps. Selected tabs can use cyan line/text and a subdued tinted panel; do not fill every control with cyan. A calm radial blue/cyan background and one thin stage ring are sufficient. Prefer neutral character lighting so interface branding does not change perceived outfit tint.
